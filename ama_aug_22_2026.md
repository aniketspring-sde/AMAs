### What is a Git commit?
- A Git commit is a snapshot of our program that is added to local history, and it can be shared  after pushing it to a remote repository.
### What is the difference between the git reset and git restore commands?
- Git reset - this is used to manage commit history and branch pointer,
- Git restore - This is used to discard or stage changes in the current working space.
### What is the use of property decorator?
- The @property decorator is a method-level decorator that is used to access that method as an attribute.
### What is the difference between CHAR and VARCHAR?
- CHAR - fixed length, fixed x bytes of memory consume.
- VARCHAR - Dynamic length, consumes the required bytes of memory.
### Which command is used to view the structure of folder?
- tree
### What are the types of Joins?
- Full join, left join, right join, inner join.
### What is duck typing?
- Duck typing is a programming concept where an object's suitability is determined by the presence of certain methods and properties, rather than its actual type or class.
### Which command is used to print a specific range of lines from a file (using sed)?
- sed -n '100,200p' filename.txt
### What is an abstract method, and why is it used?
- A method with only a method signature; it should not be a concrete method defined in an abstract class. It is used as a blueprint for subclasses;  when a class inherits from an abstract class; then the subclass must implement the parent class's abstract method.

### What is the difference between a primary key and a unique?
- A Primary Key give abilty to identify each row in a table and cannot be NULL.
- Unique ensures columns have distinct values but allows NULL entries.
### What is the purpose of the top command?
- It gives a list of active processes with system resource usage.
### What is encapsulation?
- Encapsulation is the process of bundling attributes and the methods that operate on those attributes into a class and controlling the access of attributes and methods.
### What is LSP?
- LSP stands for the Liskov Substitution Principle; it states that subclasses must be completely substitutable for their parent classes without breaking the application.
