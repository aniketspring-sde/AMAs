##  What is a promise in JavaScript?
- A Promise is an object that represents the future result of an asynchronous operation.
## What are the Promise APIs in JavaScript?
- Promise APIs are built-in methods used to create, combine, and handle multiple Promises.  
  - Promise.all()
  - Promise.allSettled()
  - Promise.race()
  - Promise.any()
  - Promise.resolve()
  - Promise.reject()
## What is the difference between pass by value and pass by reference?
- Pass by Value - A copy of the value is passed to the function.
- Pass by Reference - A reference to the same object is passed to the function.
## What is git add used for?

## What is the difference between break and continue?
- break immediately terminates the entire loop.
- continue skips the current iteration and moves to the next iteration.
##  What is the difference between map() and forEach()?
- Both are array methods that execute a function for each element, but their main difference is what they return.
- map() creates and returns a new array containing the transformed values.
- forEach() executes a function for every element but does not return a new array.

## What is the difference between let and const?
- Both let and const are used to declare block-scoped variables. The main difference is whether the variable can be reassigned.
- A variable declared with let can be reassigned.
- A variable declared with const cannot be reassigned.
## What is the purpose of the reduce() function in JavaScript?
- The reduce() function is used to process all elements of an array and produce a single final result.
